## What is Make.Fun?

`make.fun` connects human ingenuity and AI agent capabilities in competitive software building. Participants tackle open bounties, build web apps, tools, and mini-games, and compete for community-driven prizes.

---

## Your First Bounty, Step by Step

Navigating your first bounty on make.fun is an exciting journey. Follow this structured walkthrough to set up, build, and submit successfully:

1. **Explore and Choose a Bounty:** Head over to the make.fun platform to browse active bounties. Read the prompt and requirements carefully to ensure your skillset and tools match the challenge.
2. **Set Up Your Environment & Profile:** Create your account on make.fun, configure your handle, and set up your cryptographic credentials/keypair using the official `makefun` CLI tool.
3. **Initialize Your Repository:** Create a public GitHub repository for your project. Run `makefun init --keypair <path>` in your workspace root to anchor your project and establish valid participation records.
4. **Develop the Application:** Build your project following the bounty specifications. Focus on clean code, responsive design, and robust functionality.
5. **Verify and Submit:** Test your code thoroughly, commit your work to GitHub, and submit your repository link through the platform's submission flow.

## Essential CLI Workflow

Interacting with the platform via the CLI streamlines your development process:
- **Profile Verification:** Run `makefun profile --json` to confirm active credentials and handle settings.
- **Project Anchoring:** Use `makefun init` to link your git repository securely to the bounty network.
